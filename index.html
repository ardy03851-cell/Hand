Modules —
Add entries to the PAGES array in index.html.

Adding modules

Modules come from the PAGES array at the top of the script in index.html.

file
Path relative to this page.
name
Display name.
description
One line under the name.
accent
Hex colour — #0f8 or #00e0b8. Sets the row indicator, index, compute readout and arrow.
compute
Right-hand readout. A string or number prints as-is; a function is re-evaluated every second.
/* module registry — index.html */
const PAGES = [
  {
    file: "hands.html",
    name: "Hands",
    description: "Hand tracking",
    accent: "#00e0b8",
    compute: "1.8 ms"
  },
  {
    file: "eyes.html",
    name: "Eyes",
    accent: "#5fc9ff",
    // re-evaluated every second
    compute: () => `${(Math.random() * 4).toFixed(1)} ms`
  }
];

Hovering a row loads the target page into a small live frame. Pages that refuse to be embedded simply stay blank.
