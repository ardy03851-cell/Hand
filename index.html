Adding modules

The registry is the PAGES array near the top of the script in index.html. Add an entry there and it appears in the list.

file
Required. Path relative to this page.
name
Required. Display name.
description
Optional. One line, shown under the name.
accent
Optional. Hex colour — #0f8 or #00e0b8. Drives the row indicator, index, compute readout and arrow.
compute
Optional. Shown at the right of the row. A string or number is printed as-is. A function is called with the page object and re-evaluated every second — use it for live readouts.
/* ── MODULE REGISTRY ─────────────────────────── */
const PAGES = [
  {
    file: "hands.html",
    name: "Hands",
    description: "Hand tracking module",
    accent: "#00e0b8",
    compute: "1.8 ms"
  },
  {
    file: "eyes.html",
    name: "Eyes",
    description: "Eye / vision module",
    accent: "#5fc9ff",
    // live value — re-evaluated each second
    compute: () => `${(Math.random() * 4).toFixed(1)} ms`
  }
];

The accent colour is converted to RGB at render time and exposed to the row as --m. The outline halves, the swept wash and the readouts all key off it.
